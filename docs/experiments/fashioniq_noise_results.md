# FashionIQ 真实数据噪声审计结果

完成日期：2026-10-15（Asia/Hong_Kong）。代码已在本地和服务器验证。

## 全量训练划分扫描

| 类别 | 扫描图像记录 | CLIP 疑似非服装候选 | 任意规则提示的训练查询 | 文件/结构硬错误 |
|---|---:|---:|---:|---:|
| dress | 11452 | 72 | 452 | 0 |
| shirt | 19036 | 100 | 397 | 0 |
| toptee | 16121 | 86 | 281 | 0 |

累计扫描 46609 条类别图像记录。候选包括独立品牌字标、鞋类、文字页等；
查询提示还包括重复图片、空 caption、疑似矛盾描述。以上是筛查数量，不能解释成已确认噪声数量。
相同查询可能命中多条规则，各原因计数也不能直接相加作为查询数。

原始 train 图像划分全部扫描，扫描无数量截断。使用已有 LAION ViT-H/14 checkpoint、
固定提示模板及 0.03 原始余弦分差阈值，没有根据官方验证结果调阈值。
完整逐图分数、预览页和疑似三元组保留在服务器与本地 `.autodl` 目录；Git 只记录统计、代码和示例清单。

## 已核查的例子

Dress 预览页中可直接看到 JAX、JONES NEW YORK、MAGGY LONDON、LONDON TIMES 等纯品牌字标，
图片中没有服装。其中 `B00APYBNR0` 正是官方 [issue #6](https://github.com/XiaoxiaoGuo/fashion-iq/issues/6)
提到的案例；本次扫描也将它标为候选。部分三元组把真实裙子作为参考图、品牌字标作为目标图，
同时包含服装描述与非服装描述，确实存在监督质量问题。

预览中也有服装材质特写等边界情况被 CLIP 标记，说明不能直接按阈值删数据。
对 12 个由现有 BLIP 描述选出的印花/文字衣物候选做了可视检查，它们均未触发该非服装阈值。
样例包括服装整体、材质特写和宠物衣物；这是小范围功能检查，并非随机标注集或完整误报率评估。

## 视觉复核样例与清单验证

Codex 对预览中一小批清晰的独立品牌字标做了模型视觉复核，记录审核身份、理由、
图片 ID 与文件哈希。此记录不是人工真值，也不是对全部候选的确认。

- 24 张 Dress 图片进入样例排除清单。
- 它们关联的 26 条训练查询一起被隔离：5985 → 5959。
- DQU 与 DQU＋Qwen 两套真实数据加载器均通过该清单的加载检查。
- 官方验证仍为 2017 条查询、3817 张图库图片。
- 多正集合在过滤后重建：多正查询数 55 → 50；排除的图片没有被重新加入正例集合。
- 仅依据文件/结构硬错误编译的清单排除 0 条，符合此次没有文件硬错误的结果。

原始图片、原 cap JSON、split JSON 和已有缓存均未改动。清单通过训练参数显式启用；
没有重新训练模型，没有报告清洗后的 Recall 改善。

## 双图语义模型试跑限制

已编写并测试 Qwen3-VL 双图审核入口，能导出 reference/target/captions，逐句评估满足、违背或不确定，
并将模型建议与训练排除格式分开。

服务器虽有 Qwen 缓存目录，但离线加载缺少必需文件；实际试跑未能加载模型，产生 0 条语义判断。
最终程序将这种情况明确记为 `model_unavailable`，不会将失败样本当作干净或噪声。
补齐可用的本地权重后才能继续验证模型语义审核能力；本次已完成的语义候选来自规则和视觉检查。
